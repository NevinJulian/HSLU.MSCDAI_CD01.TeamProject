# HSLU.MSCDAI_CD01.TeamProject

## Setup

### 1. Create a virtual environment

**macOS / Linux**

```bash
python3 -m venv .CDA
source .CDA/bin/activate
```

**Windows (PowerShell)**

```powershell
python -m venv .CDA
.CDA\Scripts\Activate.ps1
```

### 2. Install the dependencies

```bash
pip install -r requirements.txt
```

### 3. Deactivating

```bash
deactivate
```

## Project structure

```
.
├── 01_clean_data.py                    # cleans data/raw -> data/processed
├── 02_Exploratory_Data_Analysis.ipynb  # EDA notebook
├── data/
│   ├── raw/                            # original data, do not edit
│   └── processed/                      # cleaned data, generated by 01_clean_data.py
├── doc/                                # project brief
├── example_code/                       # starter notebook provided for the course
└── requirements.txt
```
